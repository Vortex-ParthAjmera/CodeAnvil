# Workflows

## Student Workflow: Code Playback

1. Open CodeAnvil.
2. Choose an example or paste code.
3. Press Play.
4. Watch line highlight move.
5. Inspect variables, stack, output, and visual canvas.
6. Pause and step backward if confused.
7. Switch to Dry Run Practice Mode.
8. Predict next output or variable value.
9. Save the session.

## Student Workflow: Paste Any Code Later

1. Paste code into Code Playback Lab.
2. CodeAnvil detects the language.
3. Parser/analyzer builds structured trace actions.
4. Known DSA patterns map to polished animations.
5. Unknown code uses a generic execution storyboard.
6. Local LLM explains the validated trace when enabled.
7. User plays, steps, pauses, and saves the visualization.

## Student Workflow: DSA Arena

1. Choose DSA Arena.
2. Select algorithm or battle mode.
3. Pick data structure: array, graph, grid, tree.
4. Start animation.
5. Compare metrics.
6. Replay or change input.

## Student Workflow: Skill Duel

1. Pick a category.
2. Start timed challenge.
3. Answer dry-run or DSA questions.
4. Submit attempt.
5. See score, accuracy, and time.
6. Share result or retry.

## User Dashboard Workflow

1. User logs in.
2. Dashboard shows current streak and recent sessions.
3. User resumes saved playback.
4. User checks progress by topic.
5. User starts recommended next challenge.

## Admin Workflow: Challenge Management

1. Admin opens dashboard.
2. Creates challenge.
3. Adds prompt, payload, expected answer, difficulty, and category.
4. Previews challenge as student.
5. Publishes challenge.
6. Reviews attempt metrics and reports.

## Admin Workflow: Moderation

1. Admin opens report queue.
2. Reviews reported session, challenge, or user.
3. Takes action: dismiss, hide content, warn user, or suspend.
4. Action is written to audit log.

## Developer Workflow

1. Create issue or task.
2. Update docs if behavior changes.
3. Implement feature.
4. Add tests.
5. Run lint, type checks, and tests.
6. Run browser verification for UI.
7. Run security checklist for affected surfaces.
8. Open PR or deploy preview.
9. Test preview.
10. Merge and publish.

## Release Workflow

1. Freeze release candidate.
2. Run functional QA.
3. Run mobile/desktop visual QA.
4. Run security checklist.
5. Verify environment variables.
6. Verify privacy links and contact info.
7. Deploy.
8. Monitor logs and user reports.
