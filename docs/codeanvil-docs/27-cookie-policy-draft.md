# Cookie Policy Draft

This is a working draft, not legal advice.

## MVP

If CodeAnvil is frontend-only and has no login, it may not need cookies.

It may use browser storage for:

- saved sessions
- theme
- progress
- preferences

## Future Login

If Supabase Auth is added, authentication may use cookies or browser storage depending on implementation.

Users should be told:

- what is stored
- why it is stored
- how long it lasts
- how to clear it

## Analytics Later

If analytics are added:

- prefer privacy-friendly analytics
- avoid invasive tracking
- disclose analytics in privacy policy
- do not collect unnecessary personal data

## Local Storage Notice

CodeAnvil may store learning progress locally in the browser. Clearing browser data may delete local sessions.
