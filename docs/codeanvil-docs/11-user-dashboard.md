# User Dashboard

## Purpose

The user dashboard makes CodeAnvil feel personal and habit-forming.

## Main Sections

### Welcome Summary

Shows:

- current streak
- latest saved session
- dry-run accuracy
- recommended next topic

### Continue Learning

Shows:

- recently opened examples
- unfinished sessions
- recommended practice path

### Saved Sessions

Features:

- search sessions
- filter by topic/language
- resume playback
- rename session
- delete session
- change visibility later

### Progress

Shows:

- topics practiced
- examples completed
- challenge attempts
- accuracy over time
- strongest topic
- weakest topic

### Badges

Examples:

- Loop Breaker
- Stack Master
- Recursion Rookie
- Graph Runner
- Binary Searcher
- Dry Run Pro

### Duel History Later

Shows:

- challenge results
- win/loss
- best score
- friend challenges
- campus rank

### Profile

Fields:

- display name
- avatar
- campus
- year/semester optional
- public profile visibility

## User Dashboard Privacy

- Keep profile private by default.
- Let users control public display fields.
- Do not expose email publicly.
- Show leaderboard identity using display name, not email.
