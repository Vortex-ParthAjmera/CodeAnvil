# Brand Guide

## Name

CodeAnvil

## Tagline

Forge Your Logic.

## Brand Meaning

CodeAnvil represents shaping raw code understanding into strong logic.

It should feel:

- strong
- technical
- focused
- memorable
- student-friendly
- premium

## Voice

Tone:

- clear
- confident
- encouraging
- not childish
- not corporate-heavy

Example copy:

- Watch code execute.
- Forge your logic.
- Step through every variable.
- Make recursion visible.
- Battle algorithms, not confusion.

## Visual Direction

Core mood:

- dark workshop
- glowing execution line
- sharp code panels
- molten accent highlights used carefully
- clean typography

Possible colors:

- near-black background
- graphite surfaces
- warm amber accent
- electric blue secondary accent
- green success
- red error

Avoid:

- generic purple SaaS gradient
- childish cartoon styling
- beige classroom notes look
- cluttered hacker aesthetic

## Logo Direction

Ideas:

- anvil mark with code brackets
- hammer spark as execution step
- stack-frame/anvil hybrid
- letter A shaped like an anvil

Logo should work in:

- favicon
- GitHub README
- app sidebar
- PPT title slide
- social preview
