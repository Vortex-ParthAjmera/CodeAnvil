# CodeAnvil Documentation

This folder contains the working product documentation for CodeAnvil.

CodeAnvil is a visual, playable coding and DSA platform where students can watch code execute, learn algorithms through animation, practice dry runs, and later paste code in many languages for best-effort visual explanation.

## Important Security Note

No public app is literally unhackable. CodeAnvil should be designed with defense in depth: least privilege, input validation, sandboxing, row-level security, audit logs, rate limits, monitoring, privacy controls, and safe deployment defaults.
