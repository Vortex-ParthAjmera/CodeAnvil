# Roadmap And Milestones

## Milestone 1: First Visual Prototype

Deliver:

- app shell
- editor panel
- playback controls
- variable panel
- output panel
- 3 sample traces

Success:

- user can step through a simple loop

## Milestone 2: Recursion Demo

Deliver:

- call stack panel
- recursion tree visualizer
- factorial recursion trace
- fibonacci recursion trace

Success:

- recursion becomes visually clear

## Milestone 3: Practice Mode

Deliver:

- predict next value
- predict output
- score feedback
- streaks local

Success:

- user can practice dry runs, not just watch

## Milestone 4: DSA Arena Preview

Deliver:

- sorting visualizer
- BFS/DFS grid visualizer
- metrics panel

Success:

- CodeAnvil shows DSA identity

## Milestone 5: MVP Polish

Deliver:

- responsive design
- saved sessions
- examples library
- forge-workbench UI pass
- explanatory Three.js renderer for at least one flagship trace
- no inert buttons, placeholder values, or stray generated artifacts
- README
- demo script
- deployed preview

Success:

- ready to show classmates/teachers
- a student can explain the current step by looking at the code line, trace action, visual motion, and inspector together

## Milestone 6: Accounts And Dashboards

Deliver:

- Supabase Auth
- user dashboard
- cloud saved sessions
- admin dashboard foundation

Success:

- persistent user experience

## Milestone 7: Campus Layer

Deliver:

- daily challenge
- leaderboard
- challenge links
- anti-cheat basics

Success:

- students can share and compete

## Milestone 8: Universal Code Visualization

Deliver:

- language detection
- parser/AST-based trace generation
- known DSA pattern matcher
- trace action schema
- generic storyboard fallback
- local LLM explanation experiment

Success:

- users can paste common beginner code and receive a useful, honest visualization
