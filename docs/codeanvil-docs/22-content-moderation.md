# Content Moderation

## Purpose

CodeAnvil may eventually allow public sessions, profiles, comments, challenge sharing, or campus leaderboards.

Moderation protects users and keeps public content useful.

## User-Generated Content

Potential content:

- display names
- profile bios later
- saved session titles
- public code sessions
- challenge reports
- comments later

## Default Rules

- saved sessions private by default
- public sharing must be explicit
- report button on public content later
- admins/moderators can hide public content
- user emails are never displayed publicly

## Disallowed Content

- harassment
- hate speech
- threats
- sexual content involving minors
- doxxing
- malware instructions
- leaked secrets or tokens
- spam
- impersonation
- cheating marketplace content

## Moderation Queue

Report statuses:

- open
- reviewing
- resolved
- dismissed

Actions:

- hide content
- restore content
- warn user
- suspend user
- dismiss report

## Audit

Every moderation action should record:

- moderator/admin ID
- action
- target type
- target ID
- timestamp
- reason
