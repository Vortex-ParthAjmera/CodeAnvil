# Features

## Feature Priority Levels

- P0: required for first useful MVP
- P1: important after MVP
- P2: strong future upgrade
- P3: experimental or long-term

## P0: Code Playback Lab

Purpose: let students watch code execute step by step.

Features:

- Code editor
- Built-in sample examples
- Play, pause, next step, previous step
- Speed control
- Current line highlight
- Execution timeline
- Variable visualizer
- Output console
- Call stack panel
- Recursion tree for selected examples
- Dry Run Practice Mode for simple predictions
- Local saved sessions

Recommended first examples:

- sum of array
- max in array
- factorial loop
- factorial recursion
- fibonacci recursion
- binary search
- bubble sort
- BFS grid
- DFS grid

## P1: DSA Visual Battle Arena

Purpose: turn DSA algorithms into visual races and simulations.

Features:

- BFS vs DFS race
- sorting visualizer
- binary search visualizer
- graph/grid builder
- step and autoplay modes
- metrics panel
- replay mode

## P1: User Dashboard

Purpose: make CodeAnvil feel like a learning product, not a one-page toy.

Features:

- saved sessions
- recent examples
- progress by topic
- dry-run accuracy
- streaks
- badges
- recommended next practice

## P1: Admin Dashboard

Purpose: allow safe management of examples, challenges, users, reports, and content.

Features:

- overview metrics
- challenge manager
- example manager
- user moderation
- report queue
- audit logs
- announcement manager

## P2: DSA Story Mode

Purpose: teach DSA through missions.

Features:

- topic worlds
- missions
- XP and progress
- boss problems
- hints
- achievement badges
- unlockable visual themes

## P2: Skill Duel

Purpose: make learning competitive and viral.

Features:

- solo timed challenges
- local leaderboard
- daily challenge
- shareable result
- later: online 1v1 duels
- later: campus leaderboard

## P2: Universal Code Visualizer

Purpose: let users paste code in common languages and receive a best-effort visual explanation.

Features:

- language detection for pasted code
- parser/AST-based structure extraction
- pattern detection for known DSA algorithms
- mapping known patterns to polished CodeAnvil animations
- generic execution storyboard for unknown code
- local LLM explanations where useful
- confidence and unsupported-code messages
- no raw AI-generated Three.js code in the app runtime

## P3: AR Code Explainer

Purpose: point camera or upload image and explain code visually.

Early features:

- upload code image
- OCR/code extraction
- line-by-line explanation
- variable and loop arrows

Later features:

- live mobile camera mode
- overlay visual state on code
- stack frame overlay
