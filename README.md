# CodeAnvil

Forge Your Logic.

CodeAnvil is a visual coding and DSA web app where students can watch code execute step by step, inspect variables and stack frames, practice dry runs, and preview algorithm visualizations.

## MVP

The first build focuses on Code Playback Lab:

- curated execution traces
- code editor-style viewer
- playback controls
- current line highlight
- variable, stack, output, and recursion panels
- dry-run practice prompts
- local saved sessions
- DSA Arena preview

## Commands

```bash
npm install
npm run dev
npm run build
```
