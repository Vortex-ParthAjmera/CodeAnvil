# Demo Script

## Goal

Show CodeAnvil in under 2 minutes with a clear jaw-drop moment.

## One-Minute Demo

Opening:

"Most beginners do not fail because syntax is impossible. They fail because code execution is invisible. CodeAnvil makes execution visible."

Step 1:

Open Code Playback Lab.

Step 2:

Select "Factorial Recursion."

Step 3:

Press Play.

Narration:

"As the code runs, the current line glows, variables update, stack frames appear, and the recursion tree grows."

Step 4:

Pause at recursive call.

Narration:

"Instead of imagining the call stack, the student can see every function call."

Step 5:

Switch to Dry Run Practice Mode.

Narration:

"Now the student predicts what happens next. CodeAnvil turns dry runs into practice, not guessing."

Closing:

"The goal is simple: make code feel visible, playable, and understandable."
